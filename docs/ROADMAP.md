# Feuille de route

## Principe

Ne pas empiler des fonctions avant d'avoir utilisé le cycle principal dans la vie réelle. Les feedbacks enregistrés dans l'app déterminent l'ordre effectif.

## 1. Stabilisation immédiate

- installation et verrouillage des dépendances ;
- compilation, tests et build ;
- tests de composants critiques ;
- test manuel iPhone 14 Pro ;
- correctifs issus du feedback global ;
- déploiement GitHub Pages.

## 2. Boucle Claude fiable

- configuration Google réelle ;
- vérification de l'accès Drive depuis Claude ;
- test écriture directe et import de secours ;
- amélioration du prompt ;
- journal local des adaptations ;
- annulation d'une adaptation ;
- comparaison avant/après plus lisible.

## 3. Historique d'activité

- import local de fichiers FIT, GPX et TCX ;
- déduplication renforcée ;
- rapprochement automatique activité–séance ;
- calibration d'allure plus robuste ;
- graphiques hebdomadaires simples.

## 4. Garmin officiel

- candidature au programme ;
- choix d'un hébergement serveur ;
- authentification du pont ;
- synchronisation initiale et incrémentale ;
- surveillance et suppression des données ;
- tests de reprise et de doublons.

## 5. Moteur d'entraînement version 2

Uniquement après accumulation de données et retours :

- disponibilité par jour ;
- durée maximale ;
- modèle avancé de charge verticale ;
- prise en compte locale du ressenti ;
- adaptation des séances manquées ;
- terrain et technicité ;
- stratégies de progression documentées.

## 6. iOS avec Capacitor

- ajouter Capacitor au dépôt ;
- générer le projet iOS ;
- configurer icônes, écran de lancement et zones sûres ;
- étudier Sign in with Apple seulement si une distribution publique l'exige ;
- tester les plugins strictement nécessaires ;
- préparer la signature et la distribution.

## Fonctions volontairement retardées

- chat Claude dans l'app ;
- nutrition ;
- plans ultra-trail ;
- communauté ;
- parcours GPS ;
- watchOS ;
- multi-objectifs ;
- multi-utilisateur ;
- abonnement.
